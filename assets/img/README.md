# Fotos de la web

Las fotos actuales son reales, de Wikimedia Commons, con licencia libre. Los autores y licencias están en
`data/fotos.json` y se muestran en la página "Créditos de las fotos" (/creditos/). **No borres esa página**:
la mayoría de licencias obligan a citar al autor.

Cada foto tiene dos tamaños: `nombre.jpg` (1200x800) y `nombre-sm.jpg` (600x400, para móvil).
Para cambiar una foto por otra propia, sustituye los dos archivos con el mismo nombre y actualiza su entrada en
`data/fotos.json` (o bórrala si la foto es vuestra).
